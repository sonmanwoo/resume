# 손만우 — Resume

[공개 포트폴리오](https://sonmanwoo.github.io/resume/) · [스크롤 월드 이력서](https://sonmanwoo.github.io/resume/world/) · [30초 모션](https://sonmanwoo.github.io/resume/motion/)

공정 모델링, 실험·파일럿, 데이터·AI, 연구 자동화를 연결하는 손만우의 개인 포트폴리오입니다.

## 구성

- `index.html`, `styles.css`: 소개, 역량, 경력, 영상, 명함 내용과 연락처
- `world/`: 스크롤 월드 이력서(클레이 디오라마 캠퍼스 비행, 영상·포스터·명함 이미지). 엔진은 MIT 라이선스 oso95/scroll-world 수정본
- `scroll/`: 예전 스크롤 이력서 주소. 받은 링크가 계속 열리도록 `world/`로 자동 이동만 합니다
- `motion/`: 30초 모션의 인터랙티브 재생 화면
- `assets/`: 명함 다운로드, 연락처 파일, 영상과 자막
- `credits.html`: 제작·음원·글꼴 안내

HTML/CSS/JavaScript 정적 사이트입니다. GitHub Pages는 `main` 브랜치 루트에서 게시합니다. 로컬 확인: `python -m http.server 8898 --bind 127.0.0.1`.

기존 스크롤·모션 작업은 Claude로 제작했고, 공개 소개와 통합 사이트는 Codex로 제작했습니다. 기존 작업은 별도 원본으로 보존합니다. 종합 실험 저장소와 내부 지원서·작업 기록은 포함하지 않습니다.

개인 포트폴리오이며 소속 회사의 공식 웹사이트가 아닙니다. 모션의 차트는 개념도입니다.
